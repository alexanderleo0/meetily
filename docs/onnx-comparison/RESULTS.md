# Первый эксперимент: тестовая запись

Проверено 29 октября 2026 на Apple M1 Pro, 16 ГБ RAM. Исходная запись скопирована в `audio/meeting.m4a`, SHA256 копии совпал с оригиналом. Длительность 1714 секунд (28:34), 165 общих VAD-фрагментов, суммарно 1468,6 секунды с учётом padding.

| Метрика | Parakeet TDT 0.6B v3 INT8 | GigaAM v3 E2E RNNT INT8 |
|---|---:|---:|
| Время ASR | 36,91 с | 27,60 с |
| Скорость относительно речевых фрагментов | 39,8× | 53,2× |
| RTF по речи | 0,0251 | 0,0188 |
| p95 времени обработки фрагмента | 0,465 с | 0,360 с |
| Фрагментов медленнее реального времени | 0 | 0 |
| Пиковая RSS после прогрева | 1277 МиБ | 412 МиБ |

GigaAM затратил примерно на 25% меньше ASR-времени. Обе модели имеют большой вычислительный запас для этой записи. Эти цифры получены в одном последовательном прогоне на CPU, 4 потока, с прогревом, без времени скачивания, загрузки, ffmpeg и VAD. Это не гарантированная скорость внутри Meetily и не замер задержки появления текста. В текущем разбиении ожидание конца фрагмента может занимать до 20 секунд плюс обработка.

Качество: обе модели распознали основную техническую дискуссию, но в обеих расшифровках встречаются спорные имена, сокращения и термины. Без прослушивания и ручного эталона нельзя считать различия ошибками определённой модели или назвать WER. Тексты не исправлялись. Первые 90 секунд почти не содержат речи и использовались только для проверки запуска.

## Где смотреть

- `results/full/report.html`: тексты рядом и прослушивание исходных фрагментов.
- `results/full/parakeet.txt` и `results/full/gigaam.txt`: полные расшифровки.
- `results/full/summary.json`: вычислительные метрики.
- `results/full/manifest.json`: параметры, SHA256 WAV, сегменты и использованные снимки весов.
- `models.lock.json`: ревизии и SHA256 фактически скачанных файлов моделей; это фиксация использованного набора, не автоматическая установка весов по lock.

## Что проверено

- Копия аудио совпадает с оригиналом по SHA256.
- Обе модели завершили все 165 общих сегментов без ошибки.
- Границы сегментов находятся внутри записи, длина не превышает 20 секунд.
- Метрики пересчитаны из данных отдельных сегментов.
- Тесты нормализации WER и экранирования HTML проходят.
- Визуальная проверка браузером не выполнена: инструмент браузера недоступен. Структура HTML и наличие 165 кнопок прослушивания проверены программно.
